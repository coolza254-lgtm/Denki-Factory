# APK ที่ลงนามแล้ว

- [ดาวน์โหลด Denki Factory 0.2.0](denki-factory-0.2.0.apk?raw=1)
- [รายละเอียดรุ่น](v0.2.0.md)
- [SHA-256](SHA256SUMS)

APK นี้เป็นไฟล์ที่ลงนามไว้แล้ว กุญแจส่วนตัวไม่อยู่ใน Git การสร้าง APK ใหม่บนเครื่องอื่นจะใช้กุญแจของเครื่องนั้น จึงไม่ควรแทนที่ไฟล์เผยแพร่ด้วย build จาก CI ที่ลงนามคนละกุญแจ

`npm run verify:release` ตรวจ checksum ไฟล์ และทรัพยากรที่ฝังอยู่ใน APK เมื่อ push tag `v0.2.0` workflow จะรันทดสอบก่อนสร้าง GitHub Release และแนบ APK เดิมโดยไม่ลงนามใหม่ หากยังไม่มีหน้า GitHub Release ให้ดาวน์โหลดจากโฟลเดอร์นี้ได้

## Denki Factory 0.2.0

เกม Idle ธุรกิจพลังงานภาษาไทย เริ่มจากโซลาร์ 400 W และเงินสด 0 บาท ขยายผ่านโซลาร์ฟาร์ม ลม ก๊าซ จนถึงนิวเคลียร์ พร้อมระบบเงินสด ค่าเสื่อม ซ่อมบำรุง เงินกู้ ภาษีตัวอย่าง หุ้นและปันผล

รุ่นนี้เพิ่มตัวเลขนับไหล กระแสไฟตามการผลิต แผงสว่าง เมฆเคลื่อน กังหัน ไอน้ำ และเอฟเฟกต์รับทุน/อัปเกรด รองรับลดการเคลื่อนไหว ตัวเลขอนิเมชันไม่เปลี่ยนยอดเงินในเซฟ

### ติดตั้ง

ดาวน์โหลด APK เปิดไฟล์บน Android แล้วติดตั้ง อนุญาตแอปที่ใช้เปิดไฟล์ติดตั้งจากแหล่งนี้หากระบบถาม ติดตั้งทับ 0.1.0 ได้ด้วย application ID และกุญแจเดิม ไม่ต้องถอนแอปก่อนอัปเดต ควรส่งออกเซฟจากเมนูตั้งค่าก่อนเปลี่ยนเครื่องหรือล้างข้อมูล

### ผลตรวจและข้อจำกัด

ระบบเกมผ่าน unit tests 16 ข้อ และ browser tests 20 กรณี ตรวจลายเซ็น APK และ alignment แล้ว แต่ยังไม่ทดสอบรุ่นนี้บน A54 จริง และ native smoke tests ใน cloud ยังติดปัญหา System UI ของตัวจำลอง ไม่มีการอ้างว่า browser tests ทดแทนการทดสอบ native สำเร็จ

ราคา ภาษี สัญญา และทุนเป็นค่าจำลองเพื่อเกม ไม่ใช่อัตราปัจจุบันของไทย ไม่มีเสียง cloud save หรือระบบป้องกันแก้เวลาในรุ่นนี้ เกมเก็บข้อมูลในเครื่องและเล่นออฟไลน์ได้จากไฟล์ที่ฝังใน APK

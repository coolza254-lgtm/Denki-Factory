# Denki Factory 0.3.0 — แตะปั่นไฟ

เพิ่มจักรยานปั่นไฟบนหน้าโรงไฟฟ้า แตะเพื่อผลิตและขายไฟทันที แม้ตอนกลางคืน พร้อมล้อ/ข้อเหวี่ยงหมุนและเงินลอย รองรับลดการเคลื่อนไหว

- กำลัง 150 W จำกัด 4 ครั้ง/วินาที ใช้เวลาเร่ง ×365 เช่นเดียวกับเกม ได้ 3.802 Wh ต่อครั้ง ราคาคงที่ได้เงินประมาณ 0.01 บาทต่อครั้ง
- รายได้เข้าบัญชีขายไฟและคำนวณภาษีตามเดิม ช่วยเป้าหมายไฟหน่วยแรก แต่ไม่แทนเงื่อนไขผลิตของโครงการใหญ่
- เซฟเก่าใช้ต่อได้ ติดตั้งทับ 0.1.0/0.2.0 ได้ด้วยกุญแจเดิม ไม่ต้องถอนแอป ควรส่งออกเซฟสำรองก่อนอัปเดต

ตรวจระบบเกม 19 ข้อและ browser tests 22 กรณีผ่านแล้ว รายละเอียด native smoke test รุ่นล่าสุดดู docs/ANDROID-VALIDATION.md บน main ยังไม่ได้ทดสอบ Galaxy A54 จริง

ดาวน์โหลด APK เปิดบนโทรศัพท์แล้วติดตั้ง หาก Android ถาม ให้อนุญาตแอปที่ใช้เปิดไฟล์ติดตั้งจากแหล่งนี้

# Denki Factory 0.4.0 — อัปเดตในเกม

เพิ่ม ตั้งค่า → อัปเดตเกม ตรวจรุ่นล่าสุดจาก GitHub ดาวน์โหลด APK ในแอป และเปิดหน้าติดตั้งของ Android พร้อมแสดงความคืบหน้าและรายละเอียดรุ่น

- ต้องกดตรวจ/ดาวน์โหลดเอง เกมยังเล่นออฟไลน์ได้
- ตรวจ SHA-256 ขนาด package ID รุ่น และกุญแจลงนามเดิมก่อนติดตั้ง
- Android ขออนุญาตติดตั้งจาก Denki Factory ครั้งแรก แล้วผู้เล่นยืนยันติดตั้งเองทุกครั้ง
- เก็บเซฟเดิมโดยติดตั้งทับ ไม่ต้องถอนแอป

ผู้ใช้ 0.3.0 หรือเก่ากว่าต้องดาวน์โหลด APK 0.4.0 จากลิงก์มาติดตั้งทับอีกหนึ่งครั้ง จึงจะมีเมนูอัปเดตในเกมสำหรับรุ่นต่อไป

เพิ่มสิทธิ์ INTERNET สำหรับอัปเดต และ REQUEST_INSTALL_PACKAGES สำหรับเปิดตัวติดตั้ง ไม่มีสิทธิ์เข้าถึงไฟล์ทั้งเครื่อง ไม่ส่งข้อมูลเกมออกไป

ผลตรวจรุ่นนี้: unit tests 19 ข้อ, browser tests 28 กรณี ผล native/ตัวติดตั้งและข้อจำกัดดู docs/ANDROID-VALIDATION.md บน main ยังไม่ได้ลองบน Galaxy A54 จริง

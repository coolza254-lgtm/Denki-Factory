# Denki Factory 0.5.0 — แดดเล็ก ๆ กับสายลมหลังบ้าน

- เพิ่มแผงมือสอง 50 W ราคา ฿250 และ 100 W ราคา ฿600 ต่อกับระบบเดิม ซื้อซ้ำได้
- เพิ่มกังหันลมมือสอง 200 W ราคา ฿1,200 ผลิตตามความเร็วลมทั้งกลางวันและกลางคืน มีช่วงลมอ่อนและค่าบำรุงรักษา
- เพิ่มทุนเมื่อผลิตครบ 5 kWh จำนวน ฿1,000 พร้อมทางลัดซื้ออุปกรณ์และรับทุนบนหน้าแรก
- ลดประสบการณ์โครงการแรกจาก 1.4 ปีธุรกิจเหลือ 0.12 ปี (ประมาณ 2.9 ชั่วโมงจริงขั้นต่ำ ยังต้องผ่านผลผลิตและสภาพ) ส่วนบทถัดไปยังต้องบริหารต่อเนื่อง
- เพิ่มภาพวาด SVG 2D ของอุปกรณ์ ฉากหลังบ้านที่เปลี่ยนเมื่อซื้อ กังหันหมุนตามลม และไฟบ้านตอนกลางคืน รองรับลดการเคลื่อนไหว
- เซฟเดิมใช้ต่อได้ ไม่ต้องเริ่มใหม่ ติดตั้งทับด้วยกุญแจเดิม

ผลทดสอบ: unit tests 23 ข้อ, browser tests 30 กรณีที่สองขนาดจอมือถือ และแบบจำลองจบเกมราว 16.5–17 วันเมื่อเข้าเล่น 2–4 ครั้ง/วันและดูแลตามแผน ไม่ใช่การรับประกันทุกวิธีเล่น

ราคาจัดซื้อ ลม ภาษี และทุนเป็นกติกาสมมติของเกม อุปกรณ์เล็กคิดการต่อเพิ่มบนระบบเดิม ไม่ใช่ราคาติดตั้งขายไฟจริงครบชุด กังหันพิกัด 200 W ไม่ได้ผลิตเต็มพิกัดตลอดเวลา

อัปเดตจาก 0.4.0: ตั้งค่า → อัปเดตเกม → ตรวจสอบอัปเดต → ดาวน์โหลด → ติดตั้ง แล้วกดยืนยันกับ Android ไม่ต้องถอนแอป รุ่นเก่ากว่านั้นใช้ลิงก์ APK ติดตั้งทับ

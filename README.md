# Denki Factory

เกม Idle บริหารกิจการพลังงานไทยสำหรับมือถือแนวตั้ง งานภาพการ์ตูน 2D เริ่มด้วยเงินสด 0 บาท แผงโซลาร์ 400 W และแบตเตอรี่ 0.2 kWh ที่ได้รับมา ก่อนขยายไปสู่นิวเคลียร์ ผู้เล่นเป็นเจ้าของคนเดียว ไม่มีระบบจ้างพนักงาน

**[ดาวน์โหลด APK 0.5.0 สำหรับ Android](https://github.com/coolza254-lgtm/Denki-Factory/releases/download/v0.5.0/denki-factory-0.5.0.apk)** · [รายละเอียดรุ่น](releases/v0.5.0.md) · [วิธีติดตั้ง](docs/ANDROID.md)

มีทั้งเว็บแอป/PWA และ APK ที่รวมไฟล์เกมไว้ในตัว ไม่มีโฆษณาหรือการซื้อในเกม ยังไม่ได้เผยแพร่ผ่าน Play Store รองรับการติดตั้งทับ 0.1.0/0.2.0 ด้วยกุญแจเดิมเพื่อเก็บเซฟไว้

รุ่น 0.5.0 ผ่าน unit tests 23 ข้อ, browser tests 30 กรณี รวมร้านอุปกรณ์ กังหันลมกลางคืน และเซฟเก่า ส่วน native checks รุ่น 0.5.0 ติดตามใน GitHub Actions แต่ยังไม่ได้ทดสอบเล่นบน Galaxy A54 จริง ดู [ผลตรวจที่แยกผ่าน/ยังไม่ได้ทดสอบ](docs/ANDROID-VALIDATION.md)

## เริ่มพัฒนา

ต้องมี Node.js 22.12+ (ตรวจสอบด้วย Node 24.19), npm และใช้ checkout เดิม ไม่ต้องสร้าง worktree ใหม่

```sh
git clone https://github.com/coolza254-lgtm/Denki-Factory.git
cd Denki-Factory
npm ci
npm run dev
```

เริ่ม production preview:

```sh
npm run build
npm run preview
```

Vite รับฟังที่ `0.0.0.0` สำหรับสภาพแวดล้อมพัฒนา ต้องใช้ช่องทางเผยแพร่ของระบบหรือโฮสต์ HTTPS จึงจะเปิดจากโทรศัพท์ภายนอกได้ ที่อยู่ loopback ของเครื่องพัฒนาไม่ใช่ลิงก์สำหรับมือถือ

## เล่นบน Galaxy A54

นำ **ไฟล์ภายใน `dist/`** ไปวางบน static host ที่รองรับ HTTPS ที่ root ของเว็บไซต์ ไม่ต้องมี API หรือฐานข้อมูล จากนั้นเปิดเว็บไซต์ด้วย Chrome หรือ Samsung Internet และใช้เมนู “เพิ่มไปยังหน้าจอหลัก” เมื่อเบราว์เซอร์รองรับ

- ต้นแบบปรับตามความกว้างจอ ไม่ยึดขนาดพิกเซลจริงของฮาร์ดแวร์
- ทดสอบ Chromium แบบสัมผัสที่ 412×892 และ 360×780 CSS pixels ไม่ได้ทดสอบเครื่อง A54 จริงหรือ Samsung Internet จริง
- เปิดออนไลน์ครั้งแรกเพื่อโหลดไฟล์ ฟอนต์ในเครื่อง และติดตั้ง service worker ก่อนเล่นออฟไลน์
- เปลี่ยนโดเมนหรือเบราว์เซอร์จะเป็นคนละบันทึก ส่งออก JSON จากเมนูตั้งค่าก่อนย้าย
- ไม่ควรเปิดหลายแท็บเล่นพร้อมกัน เวอร์ชันนี้ยังไม่มีระบบประสานข้อมูลหลายแท็บ

## อัปเดตในเกม v0.4

ตั้งค่า → อัปเดตเกม → ตรวจสอบอัปเดต → ดาวน์โหลด → ติดตั้ง ยืนยันกับ Android เองทุกครั้ง และอนุญาตติดตั้งจาก Denki Factory ครั้งแรกเมื่อระบบถาม รุ่น 0.3.0 และเก่ากว่าต้องดาวน์โหลด 0.4.0 มาติดตั้งทับด้วยลิงก์หนึ่งครั้งก่อนจึงจะมีเมนูนี้ ไม่ต้องถอนแอปหรือเริ่มเกมใหม่ อินเทอร์เน็ตใช้เฉพาะเมื่อตรวจ/ดาวน์โหลดอัปเดต เกมเล่นออฟไลน์ได้

## ปั่นไฟ v0.3

แตะปุ่มจักรยานบนหน้าโรงไฟฟ้าเพื่อผลิตและขายไฟทันที รวมตอนกลางคืน กำลัง 150 W แตะได้สูงสุด 4 ครั้ง/วินาที คิดพลังงานตามเวลาเร่ง ×365 และราคาสัญญาปัจจุบัน มีอนิเมชันล้อ/ข้อเหวี่ยงและเงินลอย รองรับลดการเคลื่อนไหว เซฟเดิมใช้ต่อได้

## ภาพเคลื่อนไหว v0.2

ตัวเลขนับไหลสู่ยอดจริง กระแสไฟวิ่ง แผงโซลาร์สว่างเป็นจังหวะ เมฆเคลื่อน กังหันและไอน้ำขยับ พร้อมเอฟเฟกต์รับทุน/อัปเกรด ระบบเกมและรูปแบบเซฟเดิมไม่เปลี่ยน รองรับลดการเคลื่อนไหวและหยุดงานตกแต่งนอกจอ

## ระบบที่เล่นได้

- โซลาร์หลังบ้าน → โซลาร์หลังคา → โซลาร์ชุมชน → โซลาร์ฟาร์ม → ลม → ก๊าซ → นิวเคลียร์
- แดดตามชั่วโมง ฤดูกาล อากาศ กำลังผลิตจริง ขีดจำกัดส่งออก และแบตเตอรี่ที่มีการสูญเสีย
- สภาพเครื่อง อายุ การซ่อมหยุดผลิต เปลี่ยนเครื่อง และค่าเสื่อมแยกจากเงินสด
- ขยายอุปกรณ์ สัญญาคงที่/ตามช่วงเวลา เงินกู้ ดอกเบี้ย เงินต้น และภาษีตัวอย่าง
- หุ้นบริษัทสมมติ 4 บริษัท ซื้อขายจริงใน state มีค่าธรรมเนียม ต้นทุนเฉลี่ย กำไรที่ขายจริง และปันผล
- เป้าหมาย รับทุนครั้งเดียว ปลดล็อกโครงการ และเป้าหมายจบที่เดินระบบนิวเคลียร์อย่างยั่งยืน
- นโยบายซ่อมอัตโนมัติ เงินสำรอง สมุดเงินสด สรุปงวด และเส้นทางเทคโนโลยี
- บันทึกในเครื่อง ส่งออก/นำเข้า JSON ตรวจโครงสร้างบันทึก รายงานข้อผิดพลาด และจำลองออฟไลน์

หน้าใน handoff ถูกจัดกลุ่มให้ใช้ component จริงร่วมกัน ไม่รัน `.dc.html` และไม่พึ่ง runtime ของ Claude Design ระบบพนักงานถูกตัดตามคำขอล่าสุด งานเทคโนโลยีปลดล็อกตามความก้าวหน้า แทนคิววิจัยแยก

## สมดุลและสิ่งที่ย่อเพื่อเกม

1 วันจริง = 365 วันธุรกิจ คิดผลผลิตทีละ 1 ชั่วโมงเกม รายรับ/รายจ่ายเดินตามกฎเดียวกันทั้งตอนเปิดและปิดเกม จำลองออฟไลน์สูงสุด 24 ชั่วโมงจริง ส่วนที่เกินเพดานไม่สร้างทั้งรายได้และต้นทุน

หน่วย kW, kWh และหลักแยกเงินสด/ค่าเสื่อมถูกใช้ตามความหมายจริง แต่ราคาอุปกรณ์ สัญญารับซื้อ การชำระเงิน ภาษี การก่อสร้าง การอนุญาต และทุนเป็น **สมมติฐานเกม** ไม่ใช่ข้อมูลรับรองตลาดไทยปัจจุบัน อ่านรายละเอียดใน [กติกาเศรษฐกิจ](docs/ECONOMY.md)

การเติบโตถึงนิวเคลียร์ในเวลานี้อาศัยทุนเปลี่ยนผ่านสมมติ แยกจากรายได้ขายไฟ ทุนไม่เข้ารายได้จากการผลิต เป้าหมาย 15–30 วันเป็นเป้าหมายสมดุล ไม่ใช่การรับประกันเวลาเล่นทุกกลยุทธ์

ผลจำลองผู้เล่นที่ซ่อมก่อนสภาพต่ำและลงทุนเมื่อพร้อม:

| ความถี่เข้าเล่น |   จบเป้าหมาย |
| --------------- | -----------: |
| 2 ครั้ง/วัน     |   17 วันจริง |
| 3 ครั้ง/วัน     | 17 วันจริง |
| 4 ครั้ง/วัน     | 16.5 วันจริง |

ยังต้องเก็บ feedback จากผู้เล่นจริง ความสนุกและความยากยังปรับได้ ไม่ได้จำลองผู้เล่นทุกพฤติกรรม

## ทดสอบ

```sh
npm test
npm run build
npm run balance
npm run test:e2e
```

E2E ใช้ Chromium ที่ `/usr/bin/chromium` หากไม่มีให้ติดตั้งด้วย `npx playwright install chromium` หรือกำหนด `CHROMIUM_PATH` เป็น executable ของคุณ สคริปต์ balance สร้าง fixture ในโฟลเดอร์ชั่วคราวของระบบเท่านั้น ไม่แก้บันทึกผู้เล่น

- Unit tests: หน่วยพลังงาน กระแสเงินสด ซ่อม แบตเตอรี่ หุ้น ภาษี หนี้ ออฟไลน์ ป้องกันรับทุนซ้ำ และจบเกม
- Browser tests: เริ่มเกม นำทาง ซื้อ/ขาย/กู้ ยืนยัน เปลี่ยนนโยบาย ส่งออก/นำเข้า ข้อมูลเสีย เป้าหมายนิวเคลียร์ และโหลด production ขณะออฟไลน์
- `test-results/` เป็นผลทดสอบที่ไม่เข้าระบบ Git

ข้อจำกัดปัจจุบัน: ไม่มีเสียง cloud save ระบบต่อต้านแก้เวลา การจำลองความปลอดภัยนิวเคลียร์เชิงวิศวกรรม ไม่ส่งข้อมูลผู้เล่นไปบริการภายนอก

## GitHub Actions และการเผยแพร่

- **Game checks**: รัน unit tests, build, ตรวจไฟล์ APK และ browser tests เมื่อ push เข้า main หรือเปิด PR
- **Android emulator checks**: สร้าง APK ทดสอบด้วยกุญแจชั่วคราวบน runner ที่มี KVM แล้วเรียก native smoke tests เมื่อส่วนเกม/Android เปลี่ยน หรือสั่ง Run workflow เอง ไม่เผยแพร่ APK ที่ลงนามด้วยกุญแจชั่วคราว
- **Publish signed APK**: เมื่อ push tag เช่น `v0.3.0` จะรันทดสอบก่อนสร้าง GitHub Release โดยแนบ APK ที่ลงนามไว้แล้วจาก releases/ ไม่ต้องใส่กุญแจส่วนตัวใน GitHub

ผลรันจริงดูจากแท็บ Actions ผลทดสอบในเครื่องไม่ใช่การรับรองว่า workflow บน GitHub รันผ่านแล้ว หาก Actions ถูกปิดหรือ workflow ไม่ผ่าน ยังดาวน์โหลด APK จากโฟลเดอร์ releases/ ได้

สร้าง APK ใหม่ด้วย `npm run build:apk` ต้องมี JDK 21 เต็มและ Android SDK 35 ผลลัพธ์เริ่มต้นอยู่ใน artifacts/ กำหนด ANDROID_SDK_ROOT หรือ ANDROID_HOME, DENKI_SIGNING_DIR และ DENKI_APK_OUTPUT ได้ ดูรายละเอียดกุญแจและการอัปเดตในคู่มือ Android

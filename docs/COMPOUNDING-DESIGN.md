# ระบบทบต้น — แนวคิดสำหรับเลือกวงจร

สถานะ: แบบร่าง ยังไม่รวมใน APK 0.5.0 ซึ่งเพิ่มเฉพาะพลังงานเล็กและกราฟิก ระบบทบต้นต้องอยู่ในธีมพลังงาน โตแบบมีต้นทุน และยังเหมาะกับเจ้าของกิจการคนเดียว

## ตัวเลือกหลัก: โซลาร์และสายประกอบ

สายประกอบอุปกรณ์ → เครื่องประกอบแผง → แผงโซลาร์ → ไฟฟ้า → รายได้ขายไฟ → ซื้อชิ้นส่วนรอบต่อไป

เริ่มจากประกอบส่วนแผงโดยใช้เซลล์ สายไฟ และโครงที่ซื้อมา ระดับถัดไปเพิ่มสายประกอบได้เมื่อมีกำไรและชิ้นส่วนพอ ระดับบนสุดค่อยเข้ามาช่วงกิจการเติบโต เครื่องจักรไม่ได้คัดลอกตัวเองฟรี และไฟฟ้าอย่างเดียวไม่ได้แทนวัสดุ

- แบ่งไฟที่ผลิตบางส่วนไปใช้กับเครื่องประกอบได้ จึงมีทางเลือกระหว่างรายได้ทันทีจากการขายไฟกับกำลังผลิตที่จะเพิ่มในอนาคต ต้องหักไฟใช้เองออกจากยอดส่งขาย
- กำไรขายไฟเป็นงบวัสดุ เลือกสัดส่วนและเงินสำรองได้ ทุน/เงินกู้ไม่ใช่กำไรเดินระบบ
- แสดงความคืบหน้าการประกอบเป็นช่วงเล็ก ๆ แต่ส่วนแผงที่เพิ่มยังผลิตตามแดด พิกัด และสภาพ
- มีเวลาประกอบ ค่าไฟเครื่องมือ ค่าเสื่อมและค่าซ่อม พื้นที่และโครงข่ายจำกัดการขยาย
- การประกอบเองอาจลดต้นทุนจากการซื้อสำเร็จรูปในระดับพอเหมาะ ต้องตรวจสมดุลก่อนกำหนดราคา
- รายได้เพิ่มจากกำลังผลิตจริง ไม่เพิ่มอัตรารับซื้อหรือสร้างดอกเบี้ยสูงโดยไม่มีที่มา

ข้อดี: ต่อจากโซลาร์เริ่มต้นและระบบบัญชีเดิมได้ตรงที่สุด ได้ความรู้สึกเครื่องชั้นบนผลิตชั้นล่างตามที่ต้องการ

## ตัวเลือกเสริม: สวนพืชพลังงานและไบโอแก๊ส

แปลงเพาะพันธุ์ → แปลงพืชพลังงาน → ถังหมักไบโอแก๊ส → เครื่องกำเนิดไฟ → กำไรขยายแปลงและถัง

กากหมักใช้คืนเป็นปุ๋ยบางส่วนได้ พืชเติบโตโดยรับพลังงานจากแสงแดด ต้องใช้น้ำ ธาตุอาหาร พื้นที่ และเวลา ไม่ใช่วงจรพลังงานไม่สิ้นสุด ต้องมีวัตถุดิบสำรองและอัตราเปลี่ยนเป็นก๊าซ/ไฟฟ้าที่สอดคล้องกัน

ข้อดี: วงจรมีชีวิต ทำกราฟิกการเติบโตและท่อส่งก๊าซได้สนุก มีทางเลือกบริหารต่างจากโซลาร์ ข้อแลกเปลี่ยนคือเพิ่มทรัพยากรและหน้าจอ จึงเหมาะกับระบบเสริมภายหลัง

## แนวทางที่แนะนำ

ใช้โซลาร์และสายประกอบเป็นระบบหลักก่อน แล้วพิจารณาไบโอแก๊สเป็นอีกสายธุรกิจ รักษาเงื่อนไขโครงการหลักและเป้าหมายจบ 15–30 วัน ตรวจทั้งความถี่ที่ผู้เล่นเห็นความคืบหน้าและข้อจำกัดการโต โดยไม่แทนความสมจริงด้วยการคูณเงินหลายเท่าทุกนาที
